# Песочница по статистике

Шесть коротких экспериментов Монте Карло. В каждом эксперименте истина известна заранее, поэтому видно, где метод держит заявленную точность, а где ломается. Все результаты сверены с теорией в автоматических тестах.

## Эксперименты

| № | Вопрос | Вывод |
|---|---|---|
| 1 | Насколько реальное покрытие «95%» интервалов? | Интервал Вальда для доли 2% при n = 50 накрывает истину только в 64% случаев, интервал Уилсона в 92%. Для среднего чека с тяжелым хвостом t интервал при n = 30 дает около 79%, бутстреп ничуть не лучше. |
| 2 | Что будет, если заглядывать в A/B тест каждый день? | Десять заглядываний с остановкой при p меньше 0,05 дают 19% ложных срабатываний вместо 5%, пятьдесят заглядываний дают 32%. Границы Покока и О'Брайена Флеминга возвращают ровно 5%, цена за это: мощность 79% и 87% против 89% при одном взгляде в конце. |
| 3 | Множественные проверки: 100 гипотез, 10 настоящих | Без поправки в среднем 4,5 ложных находки за запуск. Бонферрони и Холм почти не ошибаются, но находят около половины эффектов. Бенджамини Хохберг находит 73% при доле ложных находок 4,4%. |
| 4 | Парадокс Симпсона | В наблюдательных данных простое сравнение показывает B хуже A на 13 п.п., хотя в каждом сегменте B лучше на 2 п.п. При случайном распределении парадокса нет. |
| 5 | Сколько шума убирает CUPED? | Дисперсия падает ровно в 1 минус ρ² раз: при корреляции 0,6 это минус 37%, при 0,9 минус 81%. Смещения нет. |
| 6 | Что если считать сессии независимыми? | При 8 сессиях на человека и внутриклассовой корреляции 0,3 тест «по сессиям» ошибается в 26% случаев вместо 5%. Тест по средним на человека держит 5%. Теоретический эффект дизайна 1 плюс (m минус 1) на ICC предсказывает 27%. |

## Как устроено

- `sims.py`: все симуляции, векторные, на NumPy. Границы Покока и О'Брайена Флеминга подбираются симуляцией так, чтобы ложных срабатываний за все заглядывания было ровно 5%. Поправки Холма и Бенджамини Хохберга написаны вручную.
- `run.py`: запускает все, пишет таблицы и семь графиков в `results/`. Занимает около 20 секунд.
- `tests/test_sims.py`: 13 тестов. Среди них сверка интервала Уилсона со scipy, проверка границ на свежих данных, проверка поправок на известном примере, сравнение с теоретическими формулами.

## Запуск

```bash
pip install -r requirements.txt
python run.py
pytest
```
